# Multi-AI Consensus Room – Judgment & Action

> 一个通过结构化多 AI 辩论与共识机制，将“模糊提问”转化为“可行动判断”的实验性工具。

## 🧭 项目简介

**Multi-AI Consensus Room** 不是一个普通的聊天玩具，而是一个**决策辅助引擎**。它通过多个 AI 角色之间**可见的、受控的辩论流程**，系统性地克服单个大模型常见的几个弱点：

- 被用户原始表述**锚定**
- 过早收敛到某个立场
- 忽略边界条件与反例
- 滑向空洞的“不可知论”

该工具的输出不是一段“很聪明的聊天记录”，而是**结构化的、可校准、可行动的现实判断**——包括判断原则、合理内核、行动建议和必要边界。

## ✨ 核心特性

| 特性 | 说明 |
|------|------|
| **命题标准化** | 保留用户原话，同时改写成可讨论、可检验的命题，并明确标出“不能下结论”的部分 |
| **维度拆解** | 概念、对象、范围、时间、条件、主体、标准、证据、反例、边界 – 系统化检查，避免盲区 |
| **独立判断** | 多个 AI 在互不可见下形成初始判断，防止“跟风污染” |
| **交叉质询 + 多轮修正** | 强制检查遗漏维度、反例边界、证据不足和过度断言，逐轮深化 |
| **合理内核提炼** | 从辩论中抽取出命题中最有价值、最稳健的部分 |
| **现实语境解释** | 将抽象结论与社会机制、本土语境、利益相关方行为模式挂钩 |
| **行动转化** | 输出可直接使用的判断原则、短期任务与长期策略 |
| **质量复核** | 主动检查是否滑向不可知论、语言是否过于学术化 |

## 🎯 设计哲学 – 做什么 & 不做什么

| ✅ 做什么 | ❌ 不做什么 |
|----------|-------------|
| 观点、策略、价值判断 | 世界模拟、沙盘、头像演出（不是另一个 MiroFish） |
| 降低单模型幻觉与偏见，展示完整推理过程 | 把问题强行套进“创业压力测试”框架 |
| 提供倾向性结论、合理内核、现实机制、行动建议、必要边界 | 写成学术审稿意见（保持对普通决策者的可用性） |
| 在无法达成共识时**诚实记录分歧**，不做虚假全体共识 | 抹平无法抹平的分歧 |

## 🔁 完整流程（11步）

```text
1. 命题标准化
2. 维度拆解
3. 独立判断（多AI）
4. 交叉质询 & 多轮修正
5. 合理内核提炼
6. 现实语境解释
7. 行动转化
8. 质量复核
9. 最终质量自检
10. 输出最终报告
11. （可选）记录未解决的分歧
```

## 🧪 适用场景

- 对某个政策、观点或行动方案需要**多于一个AI的判断**
- 希望看到**不同立场之间的真正交锋**，而不是单一模型的“平均回复”
- 需要从模糊问题中提取**当下可执行的具体建议**
- 研究或体验 **Multi-Agent 辩论 / AI 审议式民主** 的前沿产品形态
